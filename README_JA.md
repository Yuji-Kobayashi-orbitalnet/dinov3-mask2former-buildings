# DINOv3凍結とMask2Formerの建物学習

Qiita記事に対応した実装一式です。詳しい手順は ARTICLE.md を参照してください。

Linux・Python 3.11・PyTorch 2.9.1+cu128・Transformers 4.57.1を対象にしています。
画像、教師ラベル、DINOv3ソースと事前学習済み重みは別途用意します。
ZIPには学習済み重みや実データは含みません。

初めて導入する場合、ホームディレクトリに展開すると ~/dinov3_mask2former/ ができます。
そのディレクトリで sha256sum -c SHA256SUMS.article を実行してください。
既存の学習環境へ上書きするための更新パッケージではありません。

学習の入口は joint_native/train_to_convergence.py です。
joint_native/train_whu.py はモデルとデータローダーなどを提供します。
train_whu.py を直接実行すると旧方式のエポックごとのAP評価が走るため、
記事の収束確認手順では直接実行しません。

新規開始時は create_initial_checkpoint.py でCPU上にepoch 0の初期値を作成します。
これは事前学習済みDINOv3とランダム初期化した学習部分からなる初期値です。
既存の学習済みチェックポイントがある場合、この作業は不要です。

sources_input.jsonは今回のNAS配置例です。使用するデータの実パスを確認してください。
クエリ数158と学習率1e-5は今回の設定です。データに応じて確認してください。

実DINOv3とRTX PRO 6000上で確認済みなのは、従来の結合モデルでの学習です。
収束用制御と初期値作成の追加機能は、ローカルの合成入力・DINO代役を用いて確認しています。
ソフトウェアの動作確認はモデルの収束や最終精度を保証するものではありません。
